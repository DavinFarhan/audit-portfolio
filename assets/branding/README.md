# Brand Assets & Logo Showcase - Smart Contract Researcher

Koleksi aset logo dan identitas visual untuk personal branding **Smart Contract Security Researcher / Auditor**.

Folder ini berisi seluruh eksplorasi desain, aset vektor master (`.svg`), dan gambar resolusi tinggi (`.jpg`) yang dibuat selama sesi brainstorming.

---

## 🚀 Cara Melihat & Mencoba Semua Logo
1. **Mockup Dokumen Audit Lengkap (A4 PDF):**  
   Buka file **`audit_report_mockup.html`** di browser untuk melihat simulasi nyata dokumen laporan audit smart contract (Halaman Sampul + Ringkasan Eksekutif + Tabel Kerentanan). Anda bisa menekan tombol **"🖨️ Cetak / Simpan ke PDF"** untuk menyimpannya menjadi file `.pdf` asli!
2. **Katalog Seluruh Logo:**  
   Buka file **`brandmark_showcase.html`** untuk melihat dan membandingkan 25+ jenis logo yang telah dibuat di avatar X dan kop surat.

## 🎨 Sistem Warna (Aturan 60-30-10)

| Porsi | Warna | Kode Hex | Peran & Makna Filosofis |
| :---: | :--- | :---: | :--- |
| **60%** | **Putih Bersih** | `#FFFFFF` | Latar belakang lapang & ruang negatif (Transparansi mutlak, kejujuran, tanpa bias). |
| **30%** | **Deep Navy** | `#0B192C` | Struktur faset atas (Fondasi profesionalisme, komitmen, otoritas akademis). |
| **10%** | **Soft Warm Amber** | `#F59E0B` | Mata pena bawah (Kemurahan hati/generosity, pencerahan ilmu, kemudahan bagi developer). |
| *Alt* | **Emerald Green** | `#10B981` | Pilihan alternatif untuk penegas status terverifikasi (*Passed/Audited*) & amanah. |
